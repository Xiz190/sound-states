Sound States 声音的「零件车间」：主站工作 / 睡眠板块里的每一层声音，都是在这里先做出来的。 The parts workshop for Sound States: every layer of sound in the Work / Sleep boards is built here first.

七张卡片 = 七个合成引擎，全部由代码实时生成，没有一个是录音文件，也没有一个是循环采样。左边是这幅声音的声谱图（横轴时间、纵轴频率、颜色越亮越强），右边是参数，下面是一排「配方」预设。合成算法改编自 Farnell《Designing Sound》的 Pure Data 示例。 Seven cards, seven synthesis engines, all generated live in code, none a recording, none a looping sample. A spectrogram on the left (time across, frequency up, brighter = stronger), parameters on the right, recipes below. The algorithms are adapted from the Pure Data examples in Farnell's Designing Sound.

建议路径：随便挑一张卡片 → 按「试听」听它在响什么 → 换一个「配方」，听同一套算法怎么变成完全不同的声音。 Suggested path: pick any card → press Play to hear what it is → switch to another recipe and hear the same algorithm become a completely different sound.

Engine 01

风 · WIND

噪声 → 两条共振带通，中心频率+音量都由「风速」信号驱动(0.1Hz 呼吸 + 随机阵风 gust + 阵风 squall)。= Farnell p18 wind 配方。通用底，所有场景可叠。
未播放
带通噪声 · 亮带随阵风起伏
配方(点击载入 → 照此存 wind-*-bed 干声规格):
· 呼啸(Q) 往左 = 宽频气流 whoosh;往右 = 门缝/林隙「呜——」的共振啸叫(工作戏剧,别进深睡)
· 阵风 = 无规律随机起伏(泊松式,非固定周期 → 大脑抓不到规律 = 注意力透明, Huron)
· 暖↔冷 = 共振中心频率,低=低沉空旷(海风),高=明亮(林梢)
Engine 02

火 · FIRE

一个共通噪声 → 三成分合成 = Farnell p11 fire_generator:① 嘶(highpass 噪声,慢随机起伏)+ ② 胴鸣/舔舐(~60Hz 共振低频慢揺)+ ③ 噼啪(自身包络过阈触发的随机带通爆裂 = evt,同雨滴机制)。
未播放
噼啪瞬态(竖纹) + 嘶声底
配方(→ 照此存 fire-* 干声):
· 噼啪 = 泊松随机触发(非周期)+ 随机音高/衰减,每次都不一样 = 真·无限
· 余烬·将熄 = 火势/噼啪都低 → 暖稀稳,适合睡眠下行弧收束
· 胴鸣(~60Hz)给暖包裹感(Juslin 安全图式);暖↔冷 往左滚高频 → 更闷更暖
Engine 03

虫鸣 · INSECTS

~4.5kHz 近纯音(两只微失谐叠成 chorus)→ 快速脉冲列(颤 trill)门控成短 chirp → 一群个体随机散布在左右。= Farnell cricket 配方(颤速调高+相加长 → 蝉的连续 buzz)。
未播放
鸣叫脉冲 · ~4.5kHz 亮线
配方(→ 照此存 cricket-bed 等干声):
· 颤速 低 = 一声声「唧…唧」(蟋蟀);拉高+相长拉长 → 融成连续「知了——」(蝉)
· 密度 = 泊松随机的"只"数,每只音高/位置/时机都随机 = 一整片虫声场
· 夜寺·稀疏 = 密度极低 → 近零事件,深睡不抢注意(族2c)
Engine 04

底噪 · 底胶 GLUE

不是一个"要放出来的声音",而是垫在所有层下面、把整段音频融合起来的隐形底胶(像 synth pad)。= 引擎算法生成的粉噪/棕噪(§三)。常时·极低电平·稳态·察觉不到 = 掩蔽住空隙 + 给所有素材一个共同频谱地面。
未播放
粉/棕噪 · 平铺的宽底
配方(底胶只需 1–2 版,不像场景音那么多):
· 它的活儿是融合不是表现:最终合集里它一直低低垫在最下面,把风/雨/火/虫黏成"一个空间"
· 电平默认很低——正确状态是"关掉才发现原来它一直在";觉得能明显听到就是太大了
· 粉噪=通用地面;棕噪=更暖更深,睡眠下行弧收束用;起伏=极慢呼吸,别调大(大了就显形)
Engine 05

溪流滴水 · WATER

水 = 无数气泡(Farnell 水模型):每个泡 = 短时内音高上升的正弦(泡收缩→共振升)+ 快衰减。密撒 = 溪流,疏撒 = 滴水。再垫一层薄薄的湍流 hiss。
未播放
气泡瞬点 + 湍流噪声底
配方(→ 照此存 stream-bed / drip-evt 干声):
· 密度 高 = 连续溪流(族3);拉到很低 = 一滴一滴的滴水(族1 屋檐/叶尖)
· 音高 低 = 大水/深潭;高 = 细流/浅溪。每个泡音高/上升/时长都随机 = 真·无限
· 滴水 配方混响拉大 → 岩缝/屋檐的空间回响(放置门:远处滴水更耐听)
Engine 06

寺钟木鱼 · BELL

加法合成 = Farnell A0–A3 bell。一组非谐部分音(各自振幅+衰减,低频衰减长/高频快)+ 敲击瞬态。寺钟=低频·长衰减·多分音·大混响;木鱼=木质·短促"笃"·少分音·稳定节奏。音高可控。
未播放
敲击瞬态 + 衰减的分音
配方(→ 照此存 woodblock-evt / bell-evt_[音名] 干声):
· 木鱼 = 每击有轻有重、音高±25Hz微动、节奏有快有慢(真人手感,非复制粘贴);寺钟 = 稀疏敲击、大混响
· 钟声频率可选(每1/3/5分一次) → 钟声警醒,低频出现才不打扰;木鱼和寺钟可同时开两栏一起听(诵经+钟)
· 加法合成音高完全可控 → 寺钟可按音名做几个同调版(清单 bell-evt_[音名]);单击一下=只敲一下听音色
Engine 07

颗粒纹理 · GRANULAR

连续带限噪声 + 第二路噪声做摩擦振幅调制(不是一颗颗的点)。树叶窸窣 / 踩沙捏沙 / 笔尖沙沙 = 同引擎不同配方。树叶=持续+慢阵;踩沙/笔尖=每"下"一段连续摩擦(非一串点)。
未播放
颗粒事件 · 每颗一个点
配方(→ 照此存 leaves/sand/pen 干声):
· 树叶=持续泊松(风吹一片);踩沙/笔尖=成阵(密度=每秒几"阵",每阵 2–9 颗)
· 之后接入:树叶→夜森林 · 踩沙→海边(ASMR) · 笔尖→图书馆。同法可扩:杯碟碰(加法冲击)、远火车/街道(低频床)
